## 2026-10-05 · S5 字段映射「匹配关系不完整」修复（鲁棒性）

- 背景：S5 字段映射可视化只画**两端都能解析**的映射（左端须在 `templateColumns`、右端须在卡片 `cols`），任一端缺失即静默丢线，观感为"匹配关系不完整"。
- 修复（纯前端）：
  1. **连线稳定标识**：`LeftJoinModelView` 的 `AuxTable` 新增可选 `pairIds`，连线 React key 改用映射 `id`（缺省回退 `auxId-pairIndex`）；`mappingAuxTables` 透传 `pairIds`。
  2. **合并表列兜底**：`mappingModel` 的「合并表列」卡在 `table1Columns` 为空时，把已配置的 `table1Col` 并入 `cols`（`Set` 去重），已配映射不再丢线；并在可视化上方提示"尚未读取合并表字段，请先执行 S1·S2"。
  3. **自定义字段身份唯一**：自定义卡身份改用 `sourceType`（`value`），展示用 `label`；`label` 重名时追加序号；`updateMappingPair`/`connectMapping` 改按 `customDisplayToValue` 映射写回，消除同名串键。旧预设的 `materialCode`/`materialName` 也纳入列，避免丢线。
  4. **未完成映射提示**：新增 `incompleteMappingCount`（数据表取值缺模板列/数据表列；自定义取值缺模板列），在可视化上方以红色提示条数，替代"静默消失"。
- 未改动：主进程 / IPC / 预设结构 / `step2c` 填充逻辑。
- 验证：`tsc --noEmit` **0 error**。
- 版本 / 打包：本次**未递增版本、未打包**（源码 + 文档改动）。

## 2026-10-05 · S5 字段映射可视化改为「运行口径」（合并表列 / 自定义字段）

- 需求（纯前端）：核对模板表取值来源后，将第 5 步字段映射可视化右侧**简化为只区分「合并表列 / 自定义字段」**，不再单列来源辅助表；按运行口径展示，帮助用户判断取值逻辑是否正确。
- 核对结论：模板表 `table1Col` 实际从**合并表**取值——
  - 辅助表在 S1/S2 合并（`excelMerge.leftJoin`）已 LEFT JOIN **平铺进合并表**（列名冲突改名 `${列名}_${辅助表名}`）；
  - S4 `step2aJoin` 表头 = 模板列 + 合并表列（`dataCols`），为**单表**；
  - S5 `step2cFillData`（`sourceType==='table1'`）按列名 `rowData[headers.indexOf(table1Col)]` 取值，**不重读辅助表文件**。
  - 此前可视化中的「辅助表 / 数据表」分组只是来源展示启发式（`groupIdOf`），会被误读为"运行时从辅助表取值"。
- `CombinedPage.tsx`：`mappingModel` 移除 `groupIdOf` 来源分组，改为两张卡：
  - 「**合并表列**」(`id: 'map-table1'`)：`cols` = `table1Columns`（未配置时回退 `orderColumns`），`matchPairs`/`pairIds` = 全部 `sourceType==='table1'` 映射；
  - 「**自定义字段**」(`id: 'map-custom'`)：常量 / 日期 / 自定义填充规则（`sourceType !== 'table1'`）。
  - 文案：`toolbarTitle="运行口径：模板表 ←（合并表列 / 自定义字段）"`、`emptyText` 同步为「数据表取值 / 非数据表取值」。
  - `updateMappingPair` / `connectMapping` 写回逻辑不变（`map-table1` 走 table1 分支，`map-custom` 走 `sourceType` 分支）。
- 验证：`tsc --noEmit` **0 error**。
- 版本 / 打包：本次**未递增版本、未打包**（经确认暂不打包，仅源码 + 文档改动）。

## 更早的历史（摘要）

- **v3.3.0 修复**：软件关闭后双击无法启动的老问题。
  - 根因 A：`scheduleForceKill()` 创建 detached 批处理执行 `taskkill /pid /f /t` 并自删除，符合恶意软件行为特征，被 Windows Defender 拦截 → 黑屏。
  - 根因 B：NSIS 中 `taskkill /f /im explorer.exe` 后无法重启资源管理器 → 桌面/任务栏消失。
  - 修复：移除全部危险操作；退出改用 `app.exit(0)` + 800ms `process.exit(0)` 兜底；NSIS 不再终止 explorer.exe，仅用 `SHChangeNotify` 刷新图标缓存。
- **Excel 批量合并模块**（v2.7.0）：`exceljs` 纯 JS 方案，自实现 join（left/inner/right + 多字段联合匹配），预设持久化。

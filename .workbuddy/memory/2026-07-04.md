## 第三轮开发（23:00 - 23:25）

### BugFix: pdfjs worker Windows 路径问题
- **问题**：打包后转换PDF报错 `Received protocol 'd:'`
- **根因**：`GlobalWorkerOptions.workerSrc` 设为 Windows 原生路径 `D:\...`，ESM loader 要求 `file://` URL
- **修复**：用 `url.pathToFileURL(workerPath).href` 转换路径
- **验证**：Vite 构建通过 + NSIS 安装包重新打包成功（97MB）

### BugFix: Path2D is not defined（23:28）
- **问题**：打包后转换PDF报错 `Path2D is not defined`
- **根因**：pdfjs-dist v4 渲染引擎内部使用浏览器 `Path2D` 全局 API，@napi-rs/canvas 虽导出 Path2D 但不注册为全局
- **修复**：在 `getCanvas()` 中将 @napi-rs/canvas 的 `Path2D`、`ImageData`、`Image` 注入 `globalThis`
- **验证**：Vite 构建通过 + NSIS 安装包重新打包成功（97MB）

## 第四轮：QA 全面代码审查 + 批量修复（23:32 - 23:54）

### BugFix: process.getBuiltinModule is not a function
- **问题**：pdfjs-dist v4.10.38 使用 Node.js 22+ 的 `process.getBuiltinModule` 和 `Promise.withResolvers` API
- **根因**：Electron 29 内置 Node.js 20.x 不支持这两个 API
- **修复**：在 `src-electron/main/index.ts` 添加 polyfill（`eval('require')` + TC39 标准实现）
